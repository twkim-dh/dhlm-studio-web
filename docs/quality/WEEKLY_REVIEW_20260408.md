## 5. What Failed or Almost Failed

### 5.1 Daily Brief Workflow Run #1 — Exit Code 1
- **Symptom:** First scheduled run failed at exit code 1
- **Root cause:** GitHub Actions Re-run executed against an old commit SHA before scripts/send-daily-email.js had its graceful skip safeguards
- **Fix shipped:** Both generate-daily-brief.js and send-daily-email.js now soft-fail with warnings instead of throwing on missing dependencies, missing env vars, or missing markdown files
- **Lesson:** Workflows that touch multiple services must default to graceful skip per step. The cost of a missed email is far smaller than the cost of a workflow that aborts before notifying anyone

### 5.2 ioredis Race Condition on First Live Hit
- **Symptom:** /api/subscribe returned 500 in production after the initial deploy
- **Root cause:** lazyConnect:false plus enableOfflineQueue:false rejected commands issued during cold-start TLS handshake
- **Fix shipped:** lazyConnect:true, enableOfflineQueue:true, retryStrategy capped at 3, error handler logs without crashing
- **Lesson:** Serverless functions with network-bound clients need queue-on-connect semantics by default. Eager-fail is the wrong default for cold-start environments

### 5.3 Local Git PAT Missing Workflow Scope
- **Symptom:** Initial daily-brief.yml push rejected by GitHub
- **Root cause:** Local Personal Access Token had repo scope but not workflow scope
- **Workaround:** Workflow yml added via GitHub web UI separately by editor
- **Status:** Permanent fix pending (PAT scope upgrade or move workflow management to GitHub UI standard)

### 5.4 Hot Sector Card Cache Confusion
- **Symptom:** Editor reported Hot Sector card "not visible" on home page in incognito window after 82ce920 deploy
- **Root cause:** Browser-side or CDN edge cache served stale HTML; production HTML verified correct via curl
- **Fix:** No code change needed. Documented cache-buster URL pattern and DevTools "Disable cache" instructions for future verification
- **Lesson:** "Not seeing it" reports from incognito windows still need to be verified via curl against production HTML before assuming a code bug

### 5.5 send-daily-email.js Initial Brittle Failure Modes
- **Symptom:** Hard exit when ioredis or resend modules absent in workflow runner
- **Fix shipped:** Lazy require with try/catch and graceful skip
- **Lesson:** Any dependency that is "added later" must be optionally-required from day one in scripts that run in CI

## 6. What Worked Surprisingly Well

### 6.1 The 70:30 → 75:25 → 80:20 → 90:10 Tone Matrix
The decision to define explicit tone ratios per content type (Deep Dive 70:30, Daily Brief 75:25, Weekly Deep 80:20, Hot Sector 90:10) gave every report a clear voice target before drafting started. The Energy Hot Sector report wrote noticeably faster because the personality budget was bounded to two specific lines.

### 6.2 BEAF Score on the Hot Sector Itself
Self-applying BEAF to the report's own structure (in the Competitor Analysis) produced an honest 87/100 with specific gaps. The exercise turned subjective "this report is good" into objective "8 sources is the floor, we hit the floor, next time hit 12+." This is a repeatable quality discipline.

### 6.3 Three-Tier Fallback in TodayMarket
The live → cached → static fallback chain in /api/today-market means the home page hero NEVER shows "Loading..." or empty cells. First-paint visitors always see real numbers. Worth keeping as a pattern for any future market-data widgets.

### 6.4 The "Distinct Free Product" Premium Strategy Choice
Deciding to use Approach B (free Daily/Deep Dive + separate paid Hot Sector) rather than paywalling free content protects the SEO traffic engine. This was the right call before any paid product existed and locks in a structural advantage for July launch.
