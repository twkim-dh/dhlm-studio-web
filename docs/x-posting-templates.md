### Tone Bank (pick one that fits)

| Situation | Tone Line |
|---|---|
| Mixed signals | "Setup looks mixed." |
| Waiting on data | "Watch the reaction, not the headline." |
| No clean read | "Nothing clean yet." |
| Futures negative | "Futures in the red. Let's see if it holds." |

| Fed day | "Fed day. Everything else is noise until 2 PM ET." |
| CPI day | "CPI prints at 8:30 AM ET. Position sizing first." |
| Earnings day | "Earnings season. One miss can change the narrative." |

## Rules for All X Posts

1. Every number must come from live data (FMP / CoinGecko). No estimates.
2. No prediction language: "will", "should", "must", "guaranteed"
3. URL always at the end
4. Max 280 characters total — count before posting
5. Never post during market hours unless it's a breaking catalyst worth covering

## Character Count Helper

Pre-Market template without content ≈ 120 chars.  
Close template without content ≈ 100 chars.  
Remaining budget for events/tone: ~160 chars each.
